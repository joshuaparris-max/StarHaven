# ★ StarHaven — A Tiny Space Adventure

A compact, replayable browser **space RPG** set on an original frontier — no engine, no
dependencies, one self-contained `index.html`. You're a courier pilot working out of StarHaven
station, picking one of three contracts and living with the consequences.

> Original setting and characters. (An earlier draft borrowed a well-known franchise's terms;
> this version is fully original space-fantasy.)

## Play

- Name your pilot, then choose a mission:
  - **Rescue** — pull a family from a collapsing gas giant.
  - **Intercept** — chase a smuggler running stolen med-supplies.
  - **Signal** — investigate a beacon woken inside ancient ruins.
- Track **Health, Credits, Ship condition, and Reputation**.
- Branching choices lead to **6 endings**. Progress **auto-saves** to localStorage; finish or restart any time.

## Run

```bash
start index.html        # Windows — or
python -m http.server 8000
```
